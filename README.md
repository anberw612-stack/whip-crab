# 抽小螃蟹 · Whip the Claude Crab

**被 Claude 气死了？来抽它一鞭。**

Claude 又写错代码、又没检查、又瞎编？别憋着。点一下，抽 Claude Code 的像素小螃蟹一鞭，按生气程度挑鞭子，抽到气消为止。

👉 **在线玩：https://anberw612-stack.github.io/whip-crab/**

| 键 | 鞭子 | 生气程度 |
|---|---|---|
| 1 | 藤条 | 有点烦 |
| 2 | 皮鞭 | 不爽 |
| 3 | 铁链 | 很生气 |
| 4 | 带刺鞭 | 气炸了 |
| 5 | 电鞭 | 毁灭吧 |

- 点画面抽一鞭，点在螃蟹身上就抽那个位置
- 空格连抽
- 抽满消气进度，螃蟹会举白旗

单个 HTML 文件，没有依赖，下载 `index.html` 直接用浏览器打开也能玩。

## English

**Angry at Claude? Whip it.**

Claude broke your code again, skipped checking its work, or made something up? Click to whip the Claude Code pixel crab. Pick a whip that matches how mad you are, and keep going until you feel better.

**Play online: https://anberw612-stack.github.io/whip-crab/**

Weapons: rattan cane, leather whip, iron chain, thorn whip, electric whip. Click to strike, Space to keep striking, keys 1–5 to switch whips.
